# 長照個案派案管理系統 - BA 內轉率與 B 單位輪派邏輯說明書

本系統核心針對 **BA 服務項目** 設計了特殊的「內轉率計算規則」與「公平輪派排序算法」，以平衡自家單位（悠康）的派案指標與外單位輪排的公平性。以下為詳細邏輯說明。

---

## 一、 BA 內轉率計算邏輯

內轉率是以**「悠康」**（自家單位）第一時間成功接案為主體進行的統計指標。

### 1. 統計範疇 (分母維持不變)
*   **條件**：案件必須為 **BA** 服務內容，且派案類別為**新案**。
*   **新案定義**：`新案_初評`、`新案_出備`、`自行發掘` 三種派案類別。
*   符合以上條件之個案總數即為內轉率的**分母**。

### 2. 計入內轉 (分子)
符合分母條件的個案中，**僅有「自家悠康於第一時間接案」**才計入**分子**：

| 指派單位 | 派案結果 | 是否計入分子 | 說明 |
| :--- | :--- | :---: | :--- |
| **自家悠康** | 服務提供 (第一輪) | **是** | 自家第一時間接案 |
| | 案主指定 (本單位) | 否 | 個案指定悠康不計入分子 |
| | 服務提供 (第二輪) | 否 | 第一輪沒接好，不計分子（維持不計分，拉低內轉率） |
| | 出備已派案 | 否 | 自家接出備案，不計分子（維持不計分，拉低內轉率） |
| **外單位 (非悠康)** | 服務提供 (第二輪) | 否 | 第一輪悠康沒接改派外單位，不能計入內轉分子 |
| | 出備已派案 | 否 | 出備案件外派。同樣算作成功外派的成績，不計入內轉分子 |
| | 外單位自開案 | 否 | 個案指定外單位，不計入內轉分子 |
| | 其他所有結果 | 否 | 未成功接案或一般情況不計入 |

*   **計算公式**：
    $$\text{BA 內轉率} = \left( \frac{\text{悠康第一輪服務提供數}}{\text{BA 新案總數 (分母)}} \right) \times 100\%$$

---

## 二、 B 單位輪派順序與輪序次數邏輯

為確保外單位派案公平性，系統設有輪排次數累加機制（`codeDispatchCount`）。排序的核心原則是：**悠康永遠最優先，其餘單位依累計輪序次數由少到多排序**。

### 1. 懲罰挑案條款 (次數 +1，計輪派)
為維持外單位公平性，防止單位藉故挑案而不消耗輪序額度，下列情況會對指派單位的該服務碼別輪序次數進行累加（次數 +1，往後排）：

1.  **服務提供**（第一輪）：不論悠康或外單位承接，皆算輪序過（次數 +1）。
2.  **悠康接第二輪/出備案**：悠康算輪序過（次數 +1）。
3.  **懲罰挑案結果（逾時未回覆 / 無人力 / 單位因素無法接案）**：
    *   外單位若出現「逾時未回覆」、「無人力」或「單位因素無法接案」，系統強制要求填寫原因/備註，且**輪序次數照樣加 1（往後排）**。

### 2. 被動救援保護與自開案 (次數 +0，不計輪派)
為保護外單位與尊重案主意願，以下情況**不增加**單位的輪序次數，以維持其原本的優先排序：

1.  **被動救援保護**：外單位只要是接悠康流出來的「服務提供(第二輪)」或「出備已派案」，不增加其輪序次數（次數 +0，下次還能排前面）。
2.  **外單位自開案 / 案主指定(本單位)**：個案指定或外單位自開案，不增加其輪序次數（次數 +0）。
3.  **派案後取消** / **違規停派** 或案件**尚未填寫結果**（次數 +0）。

### 3. 表單下拉選單選項標示
在個案表單「派案結果」下拉選單中，選項後方的括弧標示如下：
*   `服務提供 (計輪派)`
*   `服務提供(第二輪) (不計輪派)`
*   `出備已派案 (不計輪派)`
*   `案主指定(本單位) (不計輪派)`
*   `外單位自開案 (不計輪派)`
*   `無人力 (計輪派)`
*   `逾時未回覆 (計輪派)`
*   `單位因素無法接案 (計輪派)`
*   `派案後取消 (不計輪派)`
*   `違規停派 (增加停派次數)`

---

## 三、 原因/備註必填與紀錄機制

*   當個案的派案結果選擇為 **`服務提供(第二輪)`**、**`逾時未回覆`**、**`無人力`** 或 **`單位因素無法接案`** 時，表單將動態顯示 **`原因/備註`** 欄位。
*   此備註欄位為**必填項**。若留空提交，系統會進行防呆攔截，彈出提示。
*   當個案被存檔/歸檔後，此原因將會於個案詳情面板中完整顯示以供追蹤。
